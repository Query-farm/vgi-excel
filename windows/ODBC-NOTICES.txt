This repository is a hard fork of duckdb/duckdb-odbc (tag v1.5.5.0, which
corresponds to the DuckDB 1.5.5 engine). The upstream MIT LICENSE is preserved
verbatim. Modifications introduced by Haybarn:

  - Driver identity rebranded: the registered ODBC driver name
    ("DuckDB Driver" -> "Haybarn Driver"), the default DSN ("DuckDB" ->
    "Haybarn"), the shared library name (duckdb_odbc -> haybarn_odbc), the
    SQL_DBMS_NAME / SQL_DRIVER_NAME values returned via SQLGetInfo, and the
    ODBC diagnostic vendor-identifier ("ODBC_DuckDB" -> "ODBC_Haybarn").

  - Windows driver registration renamed: the registry keys written under
    HKLM\SOFTWARE\ODBC\ODBCINST.INI and HKLM\SOFTWARE\ODBC\ODBC.INI, the
    Windows file-version metadata (CompanyName, FileDescription, ProductName,
    InternalName, OriginalFilename) in duckdb_odbc.rc.in and winsetup/setup.rc,
    and the winsetup installer dialog caption. The installer banner image
    (winsetup/banner.bmp) was replaced with Haybarn text-only art; the
    original carried the DuckDB logo mark.

  - The C API, the `duckdb::` C++ namespace, the public headers, the
    DUCKDB_VERSION macro, and all `duckdb_*` exported C-API symbols are
    preserved verbatim — Haybarn is intentionally ABI-compatible with DuckDB.
    On-disk source file names (duckdb_odbc.rc.in, duckdb_odbc.def, etc.) are
    also kept as-is so the Haybarn changes remain a thin, rebasable stack on
    top of the upstream tag.

  - The vendored DuckDB source (src/duckdb/) is generated by vendor.py against
    the Haybarn engine (Query-farm-haybarn/haybarn) instead of upstream
    duckdb/duckdb. As a result the vendored build embeds the single Haybarn
    RSA extension trust root (for both core and community extensions) and the
    haybarn-extensions.query.farm repository URLs. DuckDB-signed extensions
    will not load.

  - README rebranded; DuckDB-branded example connection strings and DSN
    references updated across the test suite to match the renamed driver.

Source for the underlying Haybarn engine (DuckDB as modified by Haybarn) is at:
https://github.com/Query-farm-haybarn/haybarn

The original duckdb-odbc project lives at:
https://github.com/duckdb/duckdb-odbc
